# Runledge — Privacy Policy

The published privacy policy for the **Runledge** running analytics app for iPhone,
served by GitHub Pages so the App Store listing has a stable public URL.

- Live page: https://ivanboklach.github.io/runledge-privacy/
- Source: [`index.html`](index.html) — one self-contained file, no build step.

Editing the file and pushing to `main` republishes the page. When the policy changes,
update the "Last updated" date at the top.
